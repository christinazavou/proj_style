# proj_style

**This repository is a fork of [FENGGENYU/proj_style](https://github.com/FENGGENYU/proj_style).**
 For more details, please refer to the original repository.

**What is different from original:**
- scripts folder: the scripts were replaced by a Makefile which includes all the corresponding steps 1-5 with explanatory comments
- all matlab and cpp files are kept as original, with only modifications in regard to more recent versions or explanatory comments. Also, some CMakeLists.txt files are added for building the C libraries, and a script to automatically install a compatible opencv.

**The results from running these experiments is part of the work presented in [An artificial neural network framework for classifying the style of cypriot hybrid examples of built heritage in 3D](https://www.sciencedirect.com/science/article/abs/pii/S1296207423001395)**
